# Archive Directory

This directory contains old/experimental files that are no longer needed but kept for reference.

## Subdirectories:

### `/yahoo_oauth_attempts/`
- Various OAuth testing scripts from Day 7
- `yahoo_oauth_final.py` is the working version (kept in root)
- `test_yahoo_verified.py` is the test script (kept in root)

### `/old_tests/`
- Test scripts from various development days
- Most functionality is now tested via `tests/test_live_system.py`

### `/old_servers/`
- Early server implementations
- `dev_server.py` is the current working server (kept in root)
- `web_app.py` is the alternate FastAPI server (kept in root)

### `/incorrect_bedrock_agents/`
- AWS Bedrock attempts (before discovering AgentCore)
- Kept for reference of what NOT to do

## Active Files (in root):
- `dev_server.py` - Main development server
- `web_app.py` - FastAPI alternative server
- `main.py` - Core application entry point
- `yahoo_oauth_final.py` - Working Yahoo OAuth script
- `test_yahoo_verified.py` - Yahoo connection test
