# Web Interface Templates

HTML templates for the FantasyAgent web interface.

## 📄 Files

### `unified.html`
Main web interface serving both platforms:
- Platform selection (Sleeper Snake/Auction, Yahoo Snake)
- Real-time draft monitoring
- AI recommendation display
- Budget tracking for auction drafts
- Responsive design for desktop and mobile

## 🚀 Access
Web interface runs at http://localhost:3001 when `unified_server.py` is running.
